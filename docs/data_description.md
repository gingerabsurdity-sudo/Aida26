# Описание исходных данных

## Назначение

В этом документе перечислены исходные наборы данных, используемые в проекте «Сетевой анализ структуры потребительских расходов муниципальных образований Свердловской области».

Исходные файлы не включены в публичный репозиторий. Для воспроизведения расчётов их необходимо получить из соответствующих источников и разместить в каталоге `raw/`.

## Используемые файлы

| Файл | Назначение |
|---|---|
| `consumption.parquet` | Помесячные данные СберИндекса о структуре потребительских расходов муниципальных образований |
| `t_dict_municipal_districts.xlsx` | Справочник муниципальных образований, идентификаторов и территориальных преобразований |
| `t_dict_municipal_districts_poly.gpkg` | Географические границы муниципальных образований для картографирования |
| `population.xlsx` | Данные о численности населения муниципальных образований |
| `salary_panel_2023_2024_sverdlovsk.xlsx` | Данные о заработной плате за 2023–2024 годы |
| `Отраслевая структура занятости.xlsx` | Данные об отраслевой структуре занятости муниципальных образований |

## Источники

**СберИндекс:**

- [Потребительские безналичные расходы на уровне муниципальных образований](https://sberindex.ru/ru/research/data-sense-opisanie-nabora-dannikh-khakatona-sberindeksa-po-munitsipalnim-dannim)
- [Данные о границах и преобразованиях муниципальных образований](https://sberindex.ru/ru/research/dataset-borders-and-changes-of-municipalities)

**Свердловскстат:**

- [Основные социально-экономические показатели](https://66.rosstat.gov.ru/main_indicators)

Файлы региональной статистики могут требовать предварительного приведения к структуре, используемой аналитическими скриптами проекта.

## Требования к воспроизведению

1. Сохранить исходные файлы в каталоге `raw/` с указанными именами.
2. Сохранить структуру переменных и идентификаторов, используемых программными модулями.
3. Запустить проект из корневого каталога командой `source("run_all.R")`.

Исходные данные не публикуются вместе с кодом. Возможность полного воспроизведения численных результатов зависит от доступности соответствующих наборов данных и их версий.
