# Описание исходных данных

## Назначение

В этом документе перечислены исходные наборы данных, используемые в проекте «Сетевой анализ структуры потребительских расходов муниципальных образований Свердловской области».

Исходные файлы не включены в публичный репозиторий. Для воспроизведения расчётов их необходимо получить из соответствующих источников и разместить в каталоге `raw/`.

## Используемые файлы

| Файл | Назначение | Источник |
|---|---|---|
| `consumption.parquet` | Помесячные данные СберИндекса о структуре потребительских расходов муниципальных образований | СберИндекс |
| `t_dict_municipal_districts.xlsx` | Справочник муниципальных образований, идентификаторов и территориальных преобразований | СберИндекс |
| `t_dict_municipal_districts_poly.gpkg` | Географические границы муниципальных образований для картографирования | СберИндекс |
| `population.xlsx` | Данные о численности населения муниципальных образований | Свердловскстат |
| `salary_panel_2023_2024_sverdlovsk.xlsx` | Данные о заработной плате за 2023–2024 годы | Свердловскстат |
| `Отраслевая структура занятости.xlsx` | Данные об отраслевой структуре занятости муниципальных образований | Свердловскстат |

Файлы региональной статистики могут требовать предварительного приведения к структуре, используемой аналитическими скриптами проекта. Подробное описание структуры файлов приведено ниже.

## Описание структуры данных Свердловскстат

### Данные о заработной плате за 2023–2024 годы

**Имя файла:** `salary_panel_2023_2024_sverdlovsk.xlsx`

**Назначение:** таблица содержит значения средней заработной платы по муниципальным образованиям Свердловской области за 2023 и 2024 годы.

#### Словарь переменных

| Поле              | Тип     | Описание                                                                   | Единица измерения                                      |
| ----------------- | ------- | -------------------------------------------------------------------------- | ------------------------------------------------------ |
| `ОКТМО`           | string  | Код муниципального образования по ОКТМО                                    | Не применимо                                           |
| `Наименование МО` | string  | Наименование муниципального образования                                    | Не применимо                                           |
| `Год`             | integer | Год, к которому относится значение средней заработной платы                | Год                                                    |
| `СредняяЗарплата` | numeric | Значение средней заработной платы | Рублей в месяц |

### Данные о численности населения муниципальных образований

**Имя файла:** `population.xlsx`

**Назначение:** таблица содержит сведения о численности населения муниципальных образований в разрезе календарных лет. 

#### Словарь переменных

| Поле              | Тип     | Описание                                                            | Единица измерения |
| ----------------- | ------- | ------------------------------------------------------------------- | ----------------- |
| `ОКТМО`           | string  | Код муниципального образования по ОКТМО                             | Не применимо      |
| `Наименование МО` | string  | Наименование муниципального образования                             | Не применимо      |
| `год`             | integer | Год, к которому относится значение численности населения            | Год               |
| `население`       | integer | Численность населения муниципального образования | Человек           |

### Данные об отраслевой структуре занятости муниципальных образований

**Имя файла:** `Отраслевая структура занятости.xlsx`

**Назначение:** таблица содержит территориально детализированные статистические показатели занятости в разрезе отраслей экономической деятельности. Наблюдения привязаны к региону и муниципальному образованию, отчётному году и периоду внутри года.

#### Словарь переменных

| Поле                     | Тип              | Описание                                                                                                                            |
| ------------------------ | ---------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `indicator_section_code` | integer / string | Код раздела статистических показателей.                                                                                             |
| `indicator_section`      | string           | Наименование раздела статистических показателей.                                                                                    |
| `indicator_code`         | string           | Идентификатор статистического показателя.                                                                                           |
| `indicator_name`         | string           | Наименование статистического показателя.                                                                                            |
| `okved2`                 | string           | Наименование отрасли или раздела экономической деятельности по классификации ОКВЭД 2.                                               |
| `region_id`              | integer / string | Идентификатор региона в источнике.                                                                                                  |
| `region_name`            | string           | Наименование региона.                                                                                                               |
| `mun_level`              | string           | Уровень муниципального образования.                                                                                                 |
| `mun_district`           | string           | Наименование муниципального района или другой территориальной единицы согласно источнику.                                           |
| `municipality`           | string           | Наименование муниципального образования.                                                                                            |
| `oktmo`                  | string           | Код ОКТМО территории.                                                                                                               |
| `mun_type`               | string           | Тип муниципального образования.                                                                                                     |
| `mun_type_oktmo`         | string           | Тип муниципального образования, связанный с классификацией ОКТМО |
| `oktmo_stable`           | string           | Признак или описание стабильности кода ОКТМО.                                                                                       |
| `oktmo_history`          | string           | Информация об истории кода ОКТМО.                                                                                                   |
| `oktmo_year_from`        | integer          | Начальный год указанного периода применимости кода ОКТМО.                                                                           |
| `oktmo_year_to`          | integer          | Конечный год указанного периода применимости кода ОКТМО.                                                                            |
| `year`                   | integer          | Отчётный год статистического наблюдения.                                                                                            |
| `indicator_value`        | numeric          | Значение статистического показателя.                                                                                                |
| `indicator_unit`         | string           | Единица измерения показателя.                                                                                                       |
| `indicator_period`       | string           | Период наблюдения внутри отчётного года.                                                                                            |
| `comment`                | string           | Дополнительная отметка или служебный комментарий источника. Семантика кодов требует уточнения.                                      |

## Требования к воспроизведению

1. Сохранить исходные файлы в каталоге `raw/` с указанными именами.
2. Сохранить структуру переменных и идентификаторов, используемых программными модулями.
3. Запустить проект из корневого каталога командой `source("run_all.R")`.

Исходные данные не публикуются вместе с кодом. Возможность полного воспроизведения численных результатов зависит от доступности соответствующих наборов данных и их версий.
